# acmenra-data — платформа разметки датасетов

MVP для Acmenra: регистрация по email, свои датасеты у каждого пользователя, загрузка
датасета одним zip в формате YOLO, галерея файлов с превью разметки и выборкой,
правка разметки в браузере, выгрузка zip, который открывает библиотека Acmenra
`acmenra-ds`. Плюс каталог опубликованных датасетов, копирование к себе, рейтинг
авторов, профиль с аватаром, настройки и админка.
Требования: [docs/prd/mvp/prd.md](docs/prd/mvp/prd.md), [docs/prd/admin-catalog/prd.md](docs/prd/admin-catalog/prd.md),
[docs/prd/profile-settings/prd.md](docs/prd/profile-settings/prd.md),
[docs/prd/leaderboard/prd.md](docs/prd/leaderboard/prd.md).

## Быстрый запуск на другом компьютере

Нужны только **git** и **uv** — менеджер Python-проектов. Python отдельно ставить не нужно:
uv сам скачает Python 3.12 и все библиотеки. На всё уходит 3–5 минут.

**1. Поставить uv** (один раз на компьютер; после установки перезапустить терминал).

Windows (PowerShell):

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

macOS и Linux:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Git для Windows — https://git-scm.com/download/win, на macOS он ставится вместе с Xcode Command Line Tools
(`xcode-select --install`).

**2. Скачать проект и поставить зависимости.** Репозиторий закрытый — git спросит вход в GitHub.

```bash
git clone https://github.com/miroslavi52452/BOX2.git
cd BOX2
uv sync
```

**3. Наполнить демо-данными** (по желанию, но без них платформа пустая). Порядок важен:
сначала датасеты, потом пользователи, потом их активность.

```bash
uv run python scripts/seed_demo.py
uv run python scripts/seed_users.py
uv run python scripts/seed_activity.py
```

- `seed_demo.py` — демо-аккаунт с тремя размеченными датасетами; логин и пароль печатает скрипт
  и они же записаны в его шапке;
- `seed_users.py` — 12 искусственных пользователей на example.com с аватарами и датасетами
  (войти под ними нельзя — пароли случайные);
- `seed_activity.py` — их просмотры, лайки, копии и скачивания, чтобы рейтинг не был пустым.

**4. Запустить.**

```bash
uv run uvicorn app.main:app --port 8765
```

Открыть http://localhost:8765, войти в демо-аккаунт или зарегистрироваться. Остановить — `Ctrl+C`.

**5. Стать админом** (по желанию): зарегистрироваться на сайте, затем в соседнем терминале:

```bash
uv run python scripts/admin.py grant ваш@email
```

После перезагрузки страницы в боковой панели появится «Админка».

### Открыть с телефона или другого ноутбука в той же сети

```bash
uv run uvicorn app.main:app --host 0.0.0.0 --port 8765
```

и открыть `http://<IP этого компьютера>:8765` (IP — `ipconfig` на Windows, `ipconfig getifaddr en0` на macOS).
Windows при первом запуске спросит разрешение для брандмауэра — разрешить для частной сети.

### Если что-то не так

| Что видно | Что сделать |
|---|---|
| `uv: command not found` | перезапустить терминал после установки uv |
| `address already in use` | порт занят — запустить с `--port 8766` и открыть этот порт |
| Хочется начать с чистого листа | остановить сервер и удалить папку `data/` — там база и все картинки |
| Стили выглядят старыми после обновления | обновить страницу с `Ctrl+F5` |

Все данные — база SQLite, картинки, превью, аватары — лежат в `data/` рядом с кодом
(путь меняется переменной `ACMENRA_DATA_DIR`). В git эта папка не попадает.

Тесты (`acmenra-ds` стоит в dev-зависимостях, ими проверяется выгрузка):

```bash
uv run pytest -q
```

### На сервере

```bash
docker build -t acmenra-data .
docker run -d -p 8000:8000 -v acmenra-data:/data -e ACMENRA_COOKIE_SECURE=1 acmenra-data
```

Демо-скрипты (`seed_*.py`) в образ не входят и на сервере с `ACMENRA_COOKIE_SECURE=1` отказываются
работать: известный пароль демо-аккаунта на боевом сервере не нужен. Админа там назначают так:
`docker exec <контейнер> uv run --no-sync python scripts/admin.py grant ваш@email`.

`ACMENRA_COOKIE_SECURE=1` — только если сайт открыт по HTTPS. Dockerfile написан,
но локально не собирался: на машине разработки нет Docker.

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `ACMENRA_DATA_DIR` | `data` | картинки, превью и база |
| `ACMENRA_DATABASE_URL` | SQLite в `ACMENRA_DATA_DIR` | строка подключения SQLAlchemy, например Postgres |
| `ACMENRA_COOKIE_SECURE` | `0` | cookie входа только по HTTPS |
| `ACMENRA_IMPORT_MAX_BYTES` | 2 ГБ | предел распакованного zip |
| `ACMENRA_IMPORT_MAX_FILES` | 20 000 | предел числа файлов в zip |
| `ACMENRA_FILE_MAX_BYTES` | 50 МБ | предел одного файла — в zip и при загрузке картинок |

## Как пользоваться

1. Зарегистрироваться (email и пароль от 8 символов, письма не отправляются).
2. Создать датасет: название, вид разметки (рамка, полигон, повёрнутая рамка — один на датасет), классы.
3. Загрузить zip-датасет или картинки в выбранную выборку. Можно перетащить на галерею.
4. Галерея: вкладки train / val / test, поиск по имени, клик по плитке открывает редактор.
5. Редактор:
   - рамка — протянуть мышью;
   - полигон — инструменты сверху: «Точки» (клики по контуру, замкнуть кликом по первой точке,
     двойным кликом или Enter), «Прямоугольник» `B` и «Эллипс» `O` (протянуть мышью, Shift — квадрат
     или круг; превращаются в полигон из 4 и 24 точек), «От руки» `F` (вести мышью по контуру —
     точки ставятся сами, лишние убираются);
   - повёрнутая рамка — «По трём точкам» (начало стороны, конец, высота) или «Протянуть» `B`
     (как обычную рамку, потом повернуть за верхнюю точку или Q / E);
   - у выбранного объекта белые точки тянутся: углы рамки, вершины полигона, углы и ручка поворота повёрнутой рамки;
   - `V` выбор, `R` рисование, `1`–`9` класс, `Del` удалить, `Ctrl+Z` отменить, `←`/`→` картинки, колесо — масштаб, пробел + мышь — сдвиг;
   - выборка картинки меняется справа вверху. Сохраняется всё само.
6. «Скачать zip» — выгрузка.

## Раскладка, профиль, настройки

Слева — боковая панель: поиск (сразу фильтрует свои датасеты, Enter ищет в каталоге),
разделы, список своих датасетов, внизу меню пользователя: «Профиль», «Настройки», «Выйти».
Панель сворачивается в полосу иконок, состояние помнится в браузере; в редакторе
по умолчанию свёрнута. Раскладка — по оболочке MagicOS (светлая тема, контент в карточке).

- **Профиль:** имя (видно в каталоге вместо скрытого email) и аватар — пересохраняется
  квадратом 256×256 в PNG без метаданных фото.
- **Настройки:** тема (светлая, тёмная, как в системе), смена email и пароля с подтверждением
  текущим паролем (смена пароля выкидывает остальные устройства), «выйти на всех других
  устройствах», удаление аккаунта с датасетами.

## Каталог

На странице своего датасета — «Опубликовать в каталоге». Опубликованный датасет
появляется во вкладке «Каталог» у всех пользователей: они видят галерею и картинки
в режиме просмотра и могут скачать zip, но ничего не могут изменить. Автор в каталоге
показан частично: `n***@gmail.com`. «Снять с публикации» возвращает датасет в закрытые.

«Скопировать к себе» (в галерее и в редакторе чужого датасета) создаёт ваш закрытый
датасет с теми же картинками, разметкой, классами и выборками — его можно править.
Копия независима: правки исходного её не трогают и наоборот. Свой датасет так же
дублируется кнопкой «Сделать копию».

## Рейтинг

Баллы — только за открытые датасеты и только за действия других людей:

| Что | Баллы |
|---|---|
| лайк | 5 |
| копия или скачивание zip (уникальный пользователь на датасет) | 10 |
| объём: каждые 10 объектов в своём опубликованном датасете | 1, не больше 100 с датасета; копии объёма не дают |
| просмотр | 0 — только счётчик на карточке |

Снятый с публикации датасет перестаёт давать баллы, действия заблокированных не считаются.
Страница «Рейтинг» — за неделю и за всё время, клик по автору открывает его публичный профиль
(`/u/<id>`, без email). В каталоге — счётчики и сортировка «Популярные». Подробно —
[docs/prd/leaderboard/prd.md](docs/prd/leaderboard/prd.md).

## Админка

`/admin` — аккаунты (регистрация, последний вход, сколько датасетов и файлов),
блокировка и удаление аккаунта вместе с его датасетами, список всех датасетов
со снятием с публикации. Закрытые датасеты админ не открывает. Для остальных
пользователей страницы нет (404).

Админа назначают только на сервере, через интерфейс нельзя:

```bash
uv run python scripts/admin.py grant user@example.com
uv run python scripts/admin.py revoke user@example.com
uv run python scripts/admin.py list
```

В Docker: `docker exec <контейнер> uv run --no-sync python scripts/admin.py grant …`
— для этого скрипт нужен в образе, см. `Dockerfile`.

## Загрузка zip

Понимает обе раскладки YOLO:

```
images/train/a.jpg  labels/train/a.txt      (Ultralytics)
train/images/a.jpg  train/labels/a.txt      (Roboflow)
```

Выборка берётся из папки: `train`, `val`/`valid`/`validation`, `test`; без такой папки — `train`.
`data.yaml` необязателен; `names` читается и списком, и словарём. Классы из архива
сопоставляются с классами датасета по имени, новые дописываются в конец. Без `data.yaml`
классы называются `class_0`, `class_1`… и переименовываются на странице датасета.

Повёрнутая рамка читается в обоих форматах: 6 чисел (Acmenra) и 9 чисел (Ultralytics).
Какой вид у строки, решает вид датасета: 9 чисел в полигоне — четырёхугольник.
После загрузки показывается отчёт: сколько добавлено, что пропущено и почему.

## Что в выгружаемом zip

```
data.yaml                      train / val / test / task / nc / names
images/train/  labels/train/
images/valid/  labels/valid/   выборка val
images/test/   labels/test/
```

Пустые выборки не пишутся. Строки `.txt`:

| Вид | Строка |
|---|---|
| detect | `class cx cy w h` |
| segment | `class x1 y1 x2 y2 …` |
| obb, формат Acmenra | `class cx cy w h угол_рад` — так читает `acmenra_ds/label/parser.py` |
| obb, формат Ultralytics | `class x1 y1 x2 y2 x3 y3 x4 y4` — docs.ultralytics.com/datasets/obb |

## Устройство

| Файл | Что делает |
|---|---|
| `app/main.py` | страницы: вход, регистрация, мои датасеты, галерея, редактор |
| `app/api.py` | JSON-API для галереи и редактора |
| `app/auth.py` | пароли (argon2), сессии, блокировка, **доступ к датасету**: `own_dataset` (менять) и `readable_dataset` (смотреть) через одну функцию `_dataset` |
| `app/db.py` | модели SQLAlchemy: пользователи, сессии, датасеты, картинки |
| `app/datasets.py` | файлы датасета, проверка картинок и фигур |
| `app/importer.py` | разбор zip |
| `app/export.py` | сборка zip |
| `app/previews.py` | превью с разметкой (Pillow), кэш на диске |
| `app/templates/` | шаблоны Jinja |
| `app/static/editor.js` | редактор на canvas |
| `app/static/gallery.js` | загрузка и правка классов в галерее |
| `scripts/seed_demo.py` | демо-аккаунт |
| `scripts/admin.py` | назначить или снять админа |
| `scripts/seed_users.py` | искусственные пользователи для показа |
| `scripts/seed_activity.py` | их просмотры, лайки, копии и скачивания |
| `app/community.py` | просмотры, лайки, переиспользования, подсчёт баллов |
| `app/profile.py` | имя, аватар, email, тема, удаление аккаунта |

Защита от подделки запросов держится на cookie `SameSite=Lax`; добавлять CORS с
передачей cookie нельзя. Фото с телефона с поворотом в EXIF поворачиваются при загрузке.

Защита от перегрузки (по итогам ревью безопасности):

- картинка больше 40 Мп отклоняется до распаковки пикселей;
- номер класса в архиве — целое от 0 до 999, координаты без `inf`/`nan`;
- после 10 неверных паролей к одному email или 30 с одного адреса вход закрыт на 15 минут,
  регистраций с одного адреса — не больше 10 за 15 минут. Счётчики в памяти процесса,
  поэтому сервис запускается одним процессом;
- больше четырёх хэшей пароля одновременно не считается (argon2 берёт 64 МБ на хэш);
- выгрузка собирается во временный файл, а не в память.

Проекты прототипа (до MVP) лежали в `data/projects/` — новая версия их не читает,
папку можно удалить.
